# 扩大美股 + 基本面/重大事件 dual-gate

## 数据
- 股票池: 标普500按 GICS 分层约 **104** 只（11 个行业，含巨头优先）
- 清晰涨跌事件: 美股约 **51944** 条；BTC 707 条（可选拼接）
- 财报: Nasdaq earnings calendar（2022→今），池内 **104/104** 命中
- 宏观重大事件: FOMC 决议日 + NFP/CPI 代理日 + 抽样 US 经济日历（约 168 天）
- FRED 利率/CPI: 本次拉取超时，特征置 0（不影响财报/FOMC 主路径）

## 解读
- 扩池 + 事件后，**全样本准确率上升**（~58%→~63%），校准集更容易摸到 80%，但测试覆盖仍远低于 30%。
- 事件特征有用，但还不足以把 dual-gate 推到 A 股里程碑的生产条。
- 拼 BTC 仍无增益。
